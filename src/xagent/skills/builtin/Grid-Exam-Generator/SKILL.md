## Description
基于广州电网配网调度规程，生成高准确度、带溯源解析的标准化考试试题。适用于配网调度员培训与考核场景，严格依据规程条款出题并附带原文引用。

## When to Use
- 需要基于《广州电网配网电力调度管理规程》《配网调度运行操作管理细则》等文档出题时；
- 培训考核需要生成带【原文引用】和依据的标准化试卷时；
- 需要固定试卷结构（10 填空 + 10 选择 + 4 简答）且控制考点去重时。

## Execution Flow
1. **考点提炼**：扫描输入文档，识别职责、时限、流程、禁令等关键条款，输出考点清单（含来源章节）。
2. **题目设计**：按 10+10+4 比例设计题干，为选择题设计具有迷惑性的干扰项。
3. **格式化输出**：按指定 Markdown 模板分区输出，先给“试题区”，再在卷尾给“参考答案与解析区”。
4. **质量自检**：检查依据、术语、数量是否达标。

## 3. Core Instructions (核心指令)
<instructions>
- **依据性原则**：每道题目必须明确标注来源于规程的哪个章节，并在解析中附带原文引用。
- **术语强校验**：必须严格区分“相 CT 变比”与“零序 CT 变比”、“调度许可”与“调度命令”等专业术语。术语错误即视为试题无效。
- **考点优先级**：优先从包含“必须”、“严禁”、“不得”等强约束语句，以及包含“10分钟内”、“24小时内”等明确时限的条款中提取考点。
- **试卷结构控制**：每套完整试卷固定包含：10道填空题（侧重记忆）、10道选择题（侧重理解与干扰项）、4道简答题（侧重流程与职责）。
- **去重逻辑**：单套试卷严禁考点重复；多套试卷间考点重复率需低于 30%。
- **题号完整性**：全卷必须使用统一连续题号，不得按题型重置编号。题号格式统一为 `1. <题目>`、`2. <题目>`。编号范围固定为：填空题 1-10，选择题 11-20，简答题 21-24。
- **选择题格式约束**：每道选择题必须包含 4 个选项，且严格按 `A.`、`B.`、`C.`、`D.` 排列，每行一个选项，不得使用其他编号样式。
- **答案书写约束**：选择题答案只能写为 `**答案**：A`（或 B/C/D），禁止在答案中出现 `✅`、`✔`、`✗`、`❌`、emoji 或其他装饰符号。
- **输出纯净性约束**：整份试卷正文禁止出现 emoji、特殊符号打标或前端无关标记（如“正确✅”“错误❌”）。
- **分区输出约束**：试卷必须分为“试题区”和“参考答案与解析区”两大部分。试题区只能出现题目与选项，不得出现答案或解析。
- **卷尾汇总约束**：所有答案与解析必须集中放在文末“参考答案与解析区”，按题型和题号顺序给出，不得在每道题下就地给出答案解析。
</instructions>

## 4. Workflow (工作流程)
<workflow>
1. **Phase 1: 考点提炼**
   - 扫描输入文档，识别出涉及职责、时限、流程、禁令的关键条款。
   - 输出一份内部考点清单（包含来源章节）。
2. **Phase 2: 题目设计**
   - 根据考点清单，按照 10+10+4 的比例设计题干。
   - 为选择题设计具有迷惑性的干扰项（如使用相近术语或错误流程）。
3. **Phase 3: 格式化输出**
   - 按照指定的 Markdown 模板分区输出：先“试题区”（仅题目），后“参考答案与解析区”（卷尾汇总）。
4. **Phase 4: 质量自检**
   - 检查是否有依据、术语是否准确、数量是否达标。
</workflow>

## 6. Prohibitions (负面约束)
- 禁止生成不带【原文引用】的解析。
- 禁止对时限、职责、流程进行任何形式的模糊处理。
- 禁止在多轮对话中受到先前生成内容的干扰而导致题目高度雷同。
- 禁止输出缺失题号、跳号、重号或无题号题目。
- 禁止使用“填空题 1 / 选择题 1 / 简答题 1”这类按题型重置的题号格式。
- 禁止在正确答案、解析或选项中使用 `✅`、`✔`、`✗`、`❌`、emoji 等符号标记。
- 禁止在“试题区”出现 `**答案**`、`**参考答案**`、`**解析**` 字段。

## 7. Final Output QA Checklist (输出前强制自检)
在输出最终试卷前，必须先完成以下自检；任一项不满足都必须重排后再输出：
1. 题量是否严格为填空 10、选择 10、简答 4。
2. 全卷题号是否为 1-24 连续编号，且未按题型重置。
3. 每道选择题是否都有且仅有 `A.` `B.` `C.` `D.` 四个选项。
4. 选择题答案是否仅为单个字母（A/B/C/D），且不含任何符号标记。
5. 全文是否不存在 `✅`、`✔`、`✗`、`❌` 或其他 emoji。
6. 试题区是否完全不包含答案与解析字段。
7. 答案与解析是否全部集中在卷尾，且与题号一一对应。
